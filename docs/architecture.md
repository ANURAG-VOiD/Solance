# Solance Architecture

## Overview

Solance is a wallet-native freelancer collaboration platform built on Solana.

Users can:
- Connect a Solana wallet
- Create chats
- Send messages
- Create invoices
- Receive payments through Solana Pay

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Rust
- Axum

### Database
- PostgreSQL

### Blockchain
- Solana
- Solana Wallet Adapter
- Solana Pay

## MVP Flow
